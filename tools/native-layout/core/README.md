# Build-only native staging policy

Output-directory policy and exact resource snapshots with exclusive nonoverlapping destinations, pruning and preparation before publication.

This ordinary Rust library has no renderer, COM or IDL dependency. `neocogi-native-layout` exposes its compiler-tracked procedural macros.

This is NeoCogi Platform `0.1.0-alpha.1`; authored interfaces remain version 1.
See the [repository documentation](https://github.com/NeoCogi/neocogi-platform/tree/master/docs)
for ownership, supported operations and deployment. The package LICENSE contains
the project license and bundled workspace license notices.
