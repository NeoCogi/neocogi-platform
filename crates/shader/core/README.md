# Portable shader compiler contracts

Generated compiler COM interfaces, immutable artifact snapshots and checked export readers. This package performs no shader compilation.

Use `abi` for generated interfaces and `PreparedShader` for bounded owned imports. Build-time binding generation uses `neocogi-platform-build`.

This is NeoCogi Platform `0.1.0-alpha.2`; authored interfaces remain version 1.
See the [repository documentation](https://github.com/NeoCogi/neocogi-platform/tree/master/docs)
for ownership, supported operations and deployment. The package LICENSE contains
the project license and bundled workspace license notices.
